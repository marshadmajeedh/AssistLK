# Individual AI Usage Log

Each team member should keep their own copy of this log.

| Date | Tool / Model | Task / Section | AI Output | Changes / Rejections | Verification |
|---|---|---|---|---|---|
| YYYY-MM-DD | e.g. ChatGPT, GitHub Copilot, Claude | e.g. feature design, bug fix | Summary of what the AI produced | What you edited, removed, or rejected | How you checked it (tests, review, experiment) |

## Instructions

- Log each AI-assisted interaction on the date it occurred.
- Record the tool/model used and the task or section it supported.
- Summarize the AI output briefly; do not copy sensitive data.
- Note any corrections, edits, or content you rejected.
- Explain how you verified the result.

> Do not back-fill fake entries.
> Do not enter passwords, API keys, or private institutional/private data into AI tools.
