# Component Ownership

| Member | Component | Agent |
|---|---|---|
| Member 1 | Service Request & Problem Management | Problem Understanding |
| Member 2 | Provider Management & Intelligent Matching | Provider Matching |
| Member 3 | Quotation, Booking & Service Coordination | Service Coordination |
| Member 4 | Tracking, Completion & Feedback | Validation & Safety |

Ownership means the member is the primary technical owner, not the only person allowed to touch those files.

Every member should be able to trace their component across:

```text
Database → Backend → React → Flutter → Agent contribution → Tests → Git evidence
```
